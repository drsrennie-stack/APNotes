How to use these notes

Each unit is built around concept cards. Inside any unit, use the View filter (Combined, Anatomy, or Physiology) and the Depth filter (Full or Essentials) to match the level you need.

Instructors: pass a course code in the URL and the page reorganizes to your syllabus. Examples: ?course=BIO004, ?course=BIO430, ?course=BIO431, ?course=BIO304. The same parameter tags every unit link so students stay in their course context.
