How to use these notes

Each unit is built around concept cards. Use the View filter (Combined, Anatomy, or Physiology) and the Depth filter (Full or Essentials) inside each unit to match your course.

Instructors can pass a course code in the URL so the page opens with the right branding and filters preset. Examples: ?course=BIO004, ?course=BIO431, ?course=BIO304. The same parameter on this page tags every unit link so students stay in their course context.
