Physiology Hub

Human Physiology Concept Notes

Fifteen physiology-focused units structured like a typical physiology course: cellular foundations, neuromuscular, endocrine, transport, then maintenance. Click any unit to open it with the Physiology view preselected.

Prepared by Dr. Sharilyn Rennie

Physiology focus, not physiology lock. Each unit opens with the Physiology view preselected. If you haven't taken anatomy yet (or want to review), switch the View filter at the top of any unit to Anatomy or Combined — the anatomy content is fully accessible.

How to use this hub

Cards link to units with the View filter preset to Physiology. The Depth filter (Full / Essentials) and View filter remain unlocked. Anatomy review is one click away inside any unit.

Two units are intentionally omitted from this hub because they're pure anatomy: Articulations (Joints) and Regional Muscle Anatomy. If you need either, the Anatomy hub has them both.
