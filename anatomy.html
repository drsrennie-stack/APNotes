Anatomy focus, not anatomy lock. Each unit opens with the Anatomy view preselected. If you want to peek at the related physiology, switch the View filter at the top of the unit to Combined or Physiology — you have full access. This hub just gets you to anatomy content faster.

How to use this hub

Each card links to a unit page with the View filter preset to Anatomy. The Depth filter (Full / Essentials) and View filter remain unlocked, so you can adjust to match your study level.

Need physiology too? Use the Physiology hub link at the top of this page, or switch the View filter inside any unit.
